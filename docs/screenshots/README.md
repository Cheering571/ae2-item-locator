# Screenshots

These are the images used by the README. Keep the file names; both READMEs reference them.

| File | Shown in |
|---|---|
| `tooltip.png` | Item tooltip listing every drive holding the item (one entry marked `(subnet)`) |
| `world-highlight.jpg` | Locked drive with shell, edge outline and beacon beam |
| `rainbow.gif` | Animated rainbow cycle: beam, highlighted blocks, link lines and slot outline sharing one colour |
| `drive-slots.png` | Drive GUI with the matching slot outlined |
| `config-unified.png` | Settings screen, one colour for everything, with its `RGB` toggle |
| `config-separate.png` | Settings screen, separate colours for beam / drive / slot, each with its own `RGB` toggle |

## Notes

- `rainbow.gif` is a downscaled re-encode of the original 15 MB screen recording (1130x960, 272
  frames): 560 px wide, every fifth frame, 48-colour palette, ~2.1 MB. Re-encode the same way if it
  is ever replaced.
- `world-highlight.jpg` is a JPEG because the full-size PNG was over 1 MB.
- To regenerate: capture at 1920x1080 or larger with the same GUI scale, then compress.
