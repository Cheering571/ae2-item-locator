# Screenshots

Drop the images into this folder with exactly these file names — the README already references them.

| File | What to capture | Notes |
|---|---|---|
| `tooltip.png` | An AE2 terminal with an item hovered, the tooltip open, showing the "Stored in N drive slots" section with at least two entries (one of them ending in `(subnet)`). | Crop to the GUI + tooltip, keep it readable. |
| `world-highlight.png` | Standing a few blocks back from a drive that is locked: translucent box + wireframe + beacon beam visible. | Include a bit of the base for context. |
| `drive-slots.png` | The drive GUI open with the slot outline on the correct disk. Prefer the 20-slot ExtendedAE drive with the disk in the **right-hand** column — it proves the addon support. | Crop to the GUI. |
| `config.png` | The settings screen (`K`) with the colour section and the HUD-position section both visible. | Crop to the window. |

Guidelines:

- 1920x1080 or larger, PNG.
- Use the same GUI scale for all four so they look consistent.
- No HUD clutter (press `F1` to hide it, but the status text at the top-left is worth keeping in
  `world-highlight.png`).
- Keep each file under ~1 MB so the repository stays light.
